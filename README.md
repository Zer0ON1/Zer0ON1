#### [IMREPO — Image Registry Studio](https://github.com/Zer0ON1/dbx-plugin-imrepo)

在同一个工作台里浏览、管理与体检 OCI / Harbor 容器镜像仓库。
基于 **OCI Distribution 标准**实现，一套代码兼容 Harbor、Docker Registry v2、Docker Hub、GHCR、ACR、TCR、ECR 等 **11 类仓库**与 **7 种认证方式**。

覆盖仓库导航、**镜像层逐层解析**、Tag 重命名与删除、**Trivy CVE 分级与阈值判定**、**孤立制品安全清理**、多架构镜像展示、注册库总览图表；并基于 **MCP 协议**把仓库操作开放给 AI 助手，写操作逐次确认。

`Go` · `原生 JavaScript` · `OCI Distribution` · `Harbor REST v2.0` · `MCP` · `Apache-2.0`
